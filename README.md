# Student Management System

A simple Windows desktop application built with C# and Windows Forms for managing student records.

## Features

- Add student records
- Update student details
- Search students by ID
- Delete student records
- Input validation
- Save student records to a local file
- View student records in a table

## Technologies Used

- C#
- Windows Forms
- .NET
- Visual Studio

## Project Structure

- `Form1.cs` - Main application window
- `RecordsForm.cs` - Student records window
- `Student.cs` - Student class
- `StudentData.cs` - Student data and file handling
- `Program.cs` - Application entry point

## How to Run

1. Download or clone the repository.
2. Open the `.sln` or `.csproj` file in Visual Studio.
3. Build the project.
4. Run the application.

## Purpose

This project was created to practice C# programming, object-oriented programming, Windows Forms development, file handling, and basic CRUD operations.
